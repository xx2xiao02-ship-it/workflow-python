## Coze 节点契约

节点 ID：`174651`；中文名称：`AIGC动画*`；接口：`add_videos`。

### 输入

| 字段 | 类型 | 来源 | 备注 |
|---|---|---|---|
| `draft_url` | String | 创建草稿 `182422.draft_url` | 必填；草稿运行时地址，项目样本已脱敏 |
| `video_infos` | String | AIGC动画 `115723.infos` | 必填；内容是视频对象数组的 JSON 字符串 |
| `scene_timelines` | Array<Object>/null | 插件可选参数 | 仅全部有效且覆盖全部视频时启用连续拼接 |
| `alpha` | Number | 插件可选参数 | 默认 1.0 |
| `scale_x` | Number | 插件可选参数 | 默认 1.0 |
| `scale_y` | Number | 插件可选参数 | 默认 1.0 |
| `transform_x` | Integer | 插件可选参数 | 默认 0 |
| `transform_y` | Integer | 插件可选参数 | 默认 0 |

`video_infos` 每项的已核对字段顺序为：
`video_url`、`width`、`height`、`start`、`end`、`duration`、`mask`、`volume`、`transition`、`transition_duration`。

### 输出

按原始 YAML 契约顺序：

1. `draft_url: String`
2. `segment_ids: Array<String>`
3. `segment_infos: Array<Object>`
4. `track_id: String`
5. `video_ids: Array<String>`

`segment_infos` 每项包含 `end: Integer`、`id: String`、`start: Integer`；时间单位为微秒。

## 原始服务行为摘要

已读取并保存来源登记：

- [`174651_coze_config.md`](../audit/source/174651_coze_config.md)
- [`source_174651_add_videos_service_excerpt.py`](../audit/source/source_174651_add_videos_service_excerpt.py)
- [capcut-mate add_videos.py 固定提交](https://github.com/Hommy-master/capcut-mate/blob/f2581bd989190ee61719f2bf50e118ab035dcc7f/src/service/add_videos.py)

已核对的原行为：

- `video_infos` 必须是 JSON 数组字符串；空数组进入完整写入流程时会被判定为无效视频信息。
- 每项要求存在 `video_url`、`start`、`end`；`start >= 0`、`end > start`。
- `start/end/duration` 转为整数，采用 Python `int` 截断，不做四舍五入。
- 未提供 `duration` 时取 `end - start`；显式 duration 必须为正数。
- `mask`、`transition`、`transition_duration` 默认 `None`；volume 缺失或为 `None` 时为 `1.0`，超出 `[0,10]` 回退为 `1.0`。
- 没有完整有效 `scene_timelines` 时保留 `video_infos` 的原始 start/end；全部有效时按实际播放时长维护连续轨道位置。
- 完整服务会下载视频、创建轨道、写入片段、保存草稿并返回动态 ID；这些行为未在本阶段执行。
