- 中文名称：AIGC动画

- 接口：`video_infos`
- 上游：批处理（`public_video_url_list`）和时间线（`timelines`）
- 下游：解说*
- 输出：`infos: String`
- 时间单位：`start`、`end`、`duration` 均为微秒

工作流固定传入：

```json
{
  "transition": "漫画撕纸",
  "transition_duration": 1000000,
  "volume": 0
}
```

`video_urls` 来源于批处理的 `public_video_url_list`，`timelines` 来源于时间线节点的 `timelines`。插件 Schema 还声明了可选 `height`、`width`、`mask`，但原始 YAML 没有给它们设置工作流固定值。

## 原始行为与逐字段结果

原始 `video_infos` 函数的行为如下：

1. 两个输入数组长度不一致时，截断到较短长度。
2. 每一项按 `duration = end - start` 计算，不换算、不舍入、不修正倒序时间线。
3. 对象字段顺序固定为：`video_url`、`start`、`end`、`duration`，之后依次追加非 `None` 的 `width`、`height`、`mask`、`transition`、`transition_duration`、`volume`。
4. 外层返回字段只有 `infos`，类型为字符串；字符串内容是 JSON 数组。
5. 缺少必需字段、缺少 `start/end` 或时间值不可相减时，保留原始 `KeyError`/`TypeError` 行为。

合成样本中输出 3 项，顺序和时间线为：

| 索引 | start | end | duration |
|---:|---:|---:|---:|
| 0 | 0 | 4000000 | 4000000 |
| 1 | 4000000 | 8500000 | 4500000 |
| 2 | 8500000 | 12000000 | 3500000 |

10 个对照场景全部通过：

- synthetic 主样本；
- 空数组；
- URL 数组较短；
- 时间线数组较短；
- 可选字段和 `None`；
- JSON 字符串输入；
- 嵌套 `input` 输入；
- 必需字段缺失；
- 时间线字段缺失；
- 无效时间线算术输入。
