# 1256 TTS 官方接口核对记录

- 地址：`https://openspeech.bytedance.com/api/v3/tts/unidirectional`
- 请求头：`X-Api-Key`、`X-Api-Resource-Id`、`X-Api-Request-Id`
- 请求体：`req_params.text`、`req_params.speaker`、`req_params.audio_params`
- 返回：HTTP Chunked Base64 音频 `data`

## 当前生产决策（2026-08-30）

- 新版大模型 TTS 与新版声音复刻的训练、状态查询、试听，统一读取 TTS 主通道的 `X-Api-Key`。
- 当前生产链路不要求也不读取 AK/SK、AppID 或 AccessToken；TTS 备用 `X-Api-Key` 只用于普通 TTS 合成跌落，不参与声音复刻训练或查询。
- `voice-clone-admin` 仅作为独立能力卡片和接口说明存在，实际凭据复用 TTS 主 Key；TikHub、BGM、TOS 的凭据保持独立。
- 下方 AK/SK、AppID 与 AccessToken 内容均为旧版接口的历史核对证据，不是当前新版生产入口。

## 2026-08-28 官方文档与真实只读核对

- [声音复刻下单及使用指南](https://www.volcengine.com/docs/6561/1167802?lang=zh)：新版 V3 的 `speaker_id` 为必填。预付费/免费音色先在新版控制台取得已有音色 ID，再上传音频训练；后付费音色无需手动购买槽位，但必须开通对应服务，并使用 `speaker_id=custom_speaker_id` + 用户自定义 `custom_speaker_id` 上传创建。旧版控制台的 AppID 与 Access Token 不属于当前生产链路。
- [大模型语音合成 API](https://www.volcengine.com/docs/6561/2228192?lang=zh)：当前“火山声音复刻大模型”参数使用复刻音色 `voice_type`，并以 `ResourceId=seed-icl-2.0` 表示 ICL 2.0；官方同时列出 `seed-icl-1.0` 作为旧版本兼容值。
- [ListSpeakers](https://api.volcengine.com/api-docs/view?action=ListSpeakers&serviceCode=speech_saas_prod&version=2025-05-20)：使用 `speech_saas_prod` OpenAPI 的 AK/SK 签名查询官方音色列表。
- [BatchListMegaTTSTrainStatus](https://api.volcengine.com/api-docs/view?action=BatchListMegaTTSTrainStatus&serviceCode=speech_saas_prod&version=2025-05-21)：使用 AK/SK 签名，并要求项目名与状态筛选条件。
- 历史核对：本机 `8768/api/voices/list-official` 曾用页面保存的 AK/SK 完成旧 OpenAPI 只读请求；该路径现已改为读取本地唯一音色目录，不再调用旧版列表接口。
- 2026-08-29 的旧 OpenAPI 只读结果仅作为迁移参考保留；当前页面与生产入口不再暴露或读取这组 AK/SK。
- 本次真实列表结果已同步到唯一音色目录；密钥值未写入报告、响应摘要或日志。

## 鉴权边界

- 普通 TTS：只使用 `X-Api-Key`；音色目录逐项提供 `speaker_id`、`resource_id` 与 `model`。
- 当前新建/登记的定制音色默认绑定 `seed-icl-2.0`，这是当前语音合成 API 文档对“声音复刻大模型 2.0”的资源值；若真实状态响应返回旧版 `seed-icl-1.0`，必须按该音色实际响应登记，不能跨版本静默替换。
- 旧版 OpenAPI 管理：历史上使用独立 AK/SK，但不参与当前 TTS 合成、训练或查询，当前生产入口不再调用。
- 旧版 Upload 兼容路径：历史公开指南使用 AppID + Access Token；这不是新版 v3 TTS/声音复刻的鉴权要求，当前代码不接入该路径。
- 配置中心不把旧版凭据列为新版必填：新版只需 TTS 主 API Key；声音复刻卡不保存单独密钥。
