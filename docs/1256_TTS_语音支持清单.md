# 1256 TTS 语音支持清单

更新时间：2026-08-01
状态：官方契约已接入；真实音色、鉴权和音频发布待验收

## 官方接口

来源：火山引擎官方《基于 HTTP Chunked 协议的单向流式合成接口》资料。

| 项目 | 官方值 |
|---|---|
| 地址 | `POST https://openspeech.bytedance.com/api/v3/tts/unidirectional` |
| 鉴权 | `X-Api-Key` |
| 资源 ID | `seed-tts-2.0` 或 `seed-icl-2.0` |
| 请求 ID | `X-Api-Request-Id`，UUID |
| 文本 | `req_params.text` |
| 音色 | `req_params.speaker`，官方音色使用目录 ID；后付费定制音色使用已创建的 `custom_speaker_id` |
| 音频参数 | `req_params.audio_params` |
| 返回音频 | HTTP Chunked Base64 `data` 分片 |

## 语音与模型

| 条目 | 模型资源 | 音色来源 | 状态 |
|---|---|---|---|
| 豆包语音合成大模型 2.0 | `seed-tts-2.0` | 豆包语音合成模型 2.0 音色列表 | 官方已确认，项目未真实调用 |
| 豆包声音复刻大模型 2.0 | `seed-icl-2.0` | 编导弹窗上传创建的定制音色目录 | 官方已确认，项目未真实调用 |
| 原 Coze 默认音色 | 未知 | `voice_id=7468518920446607398` | 仅记录，不能当作方舟 speaker |

当前代码从鉴权中心读取 TTS 主 `X-Api-Key`，从编导音色目录解析音色。预付费/免费槽位训练或更新时必须填写新版控制台已有的真实 `speaker_id`；后付费自定义创建时传固定 `speaker_id=custom_speaker_id` 和用户填写的 `custom_speaker_id`，无需手动购买槽位但必须开通服务。没有完成真实状态/TTS 验收时，不声明定制音色可用。

## 官方语言和方言

显式语种：`zh-cn`、`en`、`ja`、`es-mx`、`id`、`pt-br`、`pt`、`ko`、`it`、`de`、`fr`、`th`、`vi`、`ru`、`fil`、`ms`、`ar`、`pl`、`tr`、`sv`。

方言：`dongbei`（东北话）、`shaanxi`（陕西话）、`sichuan`（四川话）。使用方言时，speaker 必须支持对应方言。

## 音频参数

| 字段 | 支持范围 |
|---|---|
| `format` | `mp3`、`pcm`、`ogg_opus`、`wav` |
| `sample_rate` | `8000`、`16000`、`22050`、`24000`、`32000`、`44100`、`48000` |
| `speech_rate` | `-50` 到 `100`；`100` 为 2 倍速 |
| `loudness_rate` | `-50` 到 `100` |
| `silence_duration` | `0` 到 `30000` 毫秒 |
| `enable_subtitle` | 豆包语音合成大模型 2.0；中文/英文字级时间戳 |
| `pitch` | `-12` 到 `12` |

1256 原节点仍保持 `text`、`speed_ratio`、`voice_id -> data.duration`、`data.link`、`log_id`、`msg`。适配规则为：`voice_id` 映射为 `speaker`，`speed_ratio=1.1` 映射为 `speech_rate=10`。
