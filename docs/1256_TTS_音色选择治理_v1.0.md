# 1256 TTS 音色选择治理 v1.0

更新时间：2026-08-31
状态：代码与离线契约测试已完成；火山官方女声音色已登记，逐音色真实合成试听仍待验收。

## 决策边界

音色选择发生在“故事审核通过之后、TTS 合成之前”。大配音分段仍是编导层内部数据；跨到 TTS 的只有已解析的 `speaker_id` 和每段演绎参数，不把大分段规划或完整音色库传给剪辑层。

```text
用户精确 speaker_id / voice_key
  > 用户 voice_gender
  > 模型从受限候选中选择 voice_key
  > 同性别默认音色
  > 明确记录 fallback
```

模型不能凭文案判断一个真实人的性别或“听见”某个音色。模型只根据文案和故事判断声音风格，如“成熟科普”“克制悬疑”“温暖叙事”；性别来自用户偏好或项目默认策略。

## 目录与提示词

完整音色列表放在代码配置 `voice_catalog`，而不塞进系统提示词。官方音色和已训练/创建的定制音色进入同一目录。预付费/免费槽位训练时编导弹窗必须填写控制台已有真实 `speaker_id`；后付费自定义创建时传固定 `speaker_id=custom_speaker_id` 和用户自定义 `custom_speaker_id`，无需手动购买槽位但必须开通服务。每条目录项至少包含：

```json
{
  "voice_key": "female_story",
  "speaker_id": "官方/预付费音色的真实ID；后付费模式为固定协议值 custom_speaker_id",
  "custom_speaker_id": "后付费定制音色的实际唯一代号（显式自定义模式填写）",
  "display_name": "试听名称",
  "gender": "female",
  "style_tags": ["温暖", "叙事"],
  "languages": ["zh-CN"],
  "enabled": true,
  "verified": true
}
```

代码先按性别、语言和启用状态筛出最多 5 个候选；模型只看 `voice_key`、展示名、性别和风格标签，返回 `candidate_key`，不会看到或输出 `speaker_id`。解析器会拒绝未登记的 ID，并在模型不可用时回退到已登记的默认项。

## 运行配置示例

```json
{
  "tts": {
    "overall_speed_ratio": 1.05,
    "voice_selection": {
      "enabled": true,
      "voice_gender": "male",
      "style_tags": ["成熟", "科普"],
      "language": "zh-CN"
    }
  }
}
```

`voice_catalog` 是项目内部配置，不会作为 `speech_synthesis` 节点入参传入方舟接口。实际 TTS 请求只保留：`text`、`voice_id`、`speaker_id`、语速和演绎参数。

更换默认女声只需要调整项目目录中的 `defaults.female`，不需要改模型系统提示词；不得把网页展示名直接当成 `speaker_id`。
