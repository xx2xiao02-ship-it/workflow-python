# 1256 工作流三层架构

> 状态说明：本文记录的是早期实验性三层接口，不是当前正式数据收敛主链。正式治理、模块边界、TTS 时间线锁定、主键追踪、状态机、版本失效和验收门禁，以《1256 三大模块数据收敛治理准则 v1.0》为准。现有 `DirectorPlan / AssetManifest / DraftPlan` 在完成真实数据映射前只作为旁路实验保留。

## 目标

把“内容决策”“素材获取”和“剪映组装”拆开，避免模型、素材插件和剪映写入逻辑互相污染。三层之间只交换稳定 JSON 契约，不改变原 Coze 节点字段名和数组顺序。

## 三层职责

### 编导层

负责文案理解、内容分段、镜头意图、视觉风格、数字人/AIGC 路由和提示词策略。当前入口是“具体画面导演”，后续接入“镜头精细化导演”“全文视觉意图导演”和“图生视频提示词导演”。

输出：`DirectorPlan`，核心字段为 `text`、`director_plan`、`segment_beats`、`segments`。

### 素材层

负责生成或获取视频、数字人、音频、BGM 和字幕数据，并统一记录来源、地址、微秒时间线和数组索引。

输出：`AssetManifest`，核心字段为 `assets`、`duration_us`、`timeline_unit`、`director_segments`。

### 执行层

负责把素材清单转换为剪映轨道计划，再由已有 CapCut Mate 适配器执行实际草稿写入。当前默认 `effects_enabled=false`，不恢复已确认会导致剪映退出的错误特效参数。

输出：`DraftPlan`，核心字段为 `tracks`、`assets`、`duration_us`、`draft_url`。

## 边界

本次完成的是三层数据架构和无副作用离线组装，不会伪造模型、素材服务或剪映写入成功。真实生成仍需由上层 transport 提供素材结果，再把结果交给素材层和执行层。特效保持关闭，待未来使用真实兼容参数逐项验证。
