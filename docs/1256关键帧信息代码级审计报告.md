## 已核对的原始行为

1. `offsets` 和 `values` 按 `|` 分隔并分别转换为整数和浮点数。
2. 两者长度不一致时抛出原始 `ValueError` 及相同错误文本。
3. 外层循环保持 `segment_infos` 输入顺序，内层循环保持 `offsets` 输入顺序。
4. `offset` 使用片段内相对偏移：`int(offset_percent / 100 * (end - start))`。
5. 输出 `offset` 不加片段的绝对 `start`。
6. `UNIFORM_SCALE`、旋转和透明度值不做归一化。
7. `KFTypePositionX/Y` 在提供对应画布尺寸时按源码规则归一化。
8. 空 `segment_infos` 返回 `[]` JSON 字符串。
9. 缺字段、无效时间线和非法分隔字符串保留异常行为。
