# 1256「创建草稿」代码级审计报告

## 契约

- 节点：`182422`「创建草稿」；API：`create_draft`；
- 输入：`height/width`，正整数，默认 `1080/1920`；
- 输出顺序：`draft_url`、`tip_url`，均为字符串。

## 证据

真实 Coze 执行 `7668196429877870619` 已确认输入 `1920×1080`、输出两个字符串字段。Python 契约测试覆盖默认值、JSON 字符串、嵌套输入、非法尺寸和无 transport 阻断。

本地 CapCut Mate 已多次实际创建草稿，并在本轮末端链路中成功使用 `create_draft → add_videos`；创建结果随后被读取并写入 17 段视频、34 个关键帧和 34 个特效片段。

## 限制

原始插件依赖模板目录和服务端缓存，不能仅凭 Coze 输出字符串宣称内部模板文件逐字节等价；当前结论是输入输出契约通过、本地服务可执行。
