## 4. 逐节点登记所需字段

每次推进一个节点时，登记表至少补齐：

- 中文节点名、原始节点 ID、节点类型和上/下游中文节点名；
- 输入字段名、类型、默认值、真实数量、数组顺序和来源路径；
- 输出字段名、类型、真实数量、数组顺序、时间线 `start/end` 和时间单位；
- 原始 Coze 代码或插件源码的只读路径；
- Python 实现、Schema、适配器、样本、单元测试和新旧对照模块；
- synthetic、真实页面结构、真实完整值三种证据分别标记；
- 超时、重试、异步任务、异常分支和当前阻断原因。

页面字段全量版本见脱敏快照；旧 Coze 机器可读登记表已随旧 105880 链路归档。当前实现和验收状态以 `src/workflow_1256/governance/node_registry.py` 与 `docs/TTS-STT字幕链路治理记录_20260823.md` 为准。
