## 原行为保留

- `duration` 转为 0.1 秒单位并使用 Python `round`。
- 所有镜头先分配 4.0 秒，最后一个镜头的基础时长为 0.1 秒；单镜头上限为 10.0 秒。
- 额外时长按去除空白、标点、分隔符和控制字符后的文本有效长度逐 0.1 秒分配；相同评分按原索引优先。
- `clip_duration` 保留 1 位小数；`int_duration` 向上取整且最低为 4。
- 时间线按累计时长比例换算为原始微秒区间，最后一个 `end` 严格等于输入时间线的 `end`。
- 无效时长、空镜头、无效时间线、镜头必填字段缺失和时长/镜头数量不满足边界时，返回四个空数组。
- `shots` 和单条 `timelines` 支持原代码的 JSON 字符串包装形式。
