## 已读取的原始实现行为

来自 `Hommy-master/capcut-mate` 提交 `f2581bd989190ee61719f2bf50e118ab035dcc7f`：

1. 从 `draft_url` 提取 `draft_id`，并要求草稿存在于服务缓存。
2. 解析 `keyframes` JSON 字符串，必须是数组。
3. 每项必须有 `segment_id`、`property`、`offset`、`value`。
4. 支持 11 种关键帧属性；offset 必须是非负数字。
5. offset 按微秒处理，并转换为片段内相对位置后限制在 `0..1`。
6. 找不到片段、片段类型不支持或属性无效时跳过该项，继续处理其他项。
7. `affected_segments` 按首次出现顺序去重。
8. 所有项处理后保存草稿；保存失败抛出草稿写入错误。
9. 异步入口通过草稿锁串行化写入，默认锁等待 30 秒。
