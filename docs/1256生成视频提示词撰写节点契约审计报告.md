## 输入输出契约

195692 的输入来自“首尾帧顺延”（170263）：

| 批处理字段 | 类型 | 当前项传给 LLM 的字段 |
|---|---|---|
| `items` | object[] | 当前组一个 `items` 对象 |
| `motion_seed` | object[] | 当前组一个 `{motion_seed: string[]}` 对象 |
| `ref_image` | object[] | 当前组一个 `{ref_image: string[]}`，再取内部 `ref_image` 数组作为视觉输入 |
| `clip_duration` | object[] | 当前组一个 `{clip_duration: number[]}` 对象 |

LLM 节点的单项输入为：

- `items: object`，包含 `visual_core`、`visual_story`；
- `ref_image: image[]`；
- `motion_seed: object`，包含 `motion_seed: string[]`；
- `clip_duration: object`，包含 `clip_duration: number[]`。

单项输出：

1. `plans: object[]`；
2. `reasoning_content: string`；
3. `visual_lock: string`。

每个 `plans` 项包含：

- `shot_index: integer`；
- `duration: integer`；
- `stages: object[]`，每项包含 `action: string`、`camera_motion: string`、`time_range: string`。

本地实现要求 `plans` 数量必须等于当前 `clip_duration.clip_duration` 数量；批处理输出 `plan_out_list` 必须保持 195692 的组顺序。
