# 1256 素材层首尾帧可选开关 v1

## 用户输入

素材生产层增加布尔输入：

```json
{
  "use_frame_continuity": false
}
```

- `true`：启用首尾帧连续逻辑。普通镜头使用当前镜头首帧，并把下一普通镜头首帧作为尾帧；数字人相邻位置仍然断开。
- `false`：关闭首尾帧连续逻辑。普通镜头只传首帧，`last_frame_url` 和 `ref_image_e` 统一为空字符串。
- 用户界面默认值为 `false`，因此用户不选择时不会使用首尾帧逻辑。

## 兼容规则

历史内部调用如果完全没有传 `use_frame_continuity`，代码保留旧行为，以免已经存在的工作流被静默改变。新用户输入界面必须显式传入 `false` 或 `true`。

## 生效位置

开关同时作用于：

1. `170263` 首尾帧顺延：控制 `ref_image_e` 是否填充。
2. `113743` 提示词生成：控制 `last_frame_url` 是否传给视频提示词和后续素材任务。
3. `110697` 视频批处理：最终发送给 `video_generate` 前再次强制清空尾帧，防止上游误传。

这样即使上游某个节点没有正确清空，素材生产层的最终请求仍遵循用户选择。
