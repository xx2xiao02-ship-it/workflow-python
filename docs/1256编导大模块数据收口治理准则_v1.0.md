# 1256 编导大模块数据收口治理准则 v1.0

## 1. 目标与边界

本准则只治理“编导层内部结果如何收口”。它不迁移第二个节点，不改写原 Coze 节点输出，不调用模型、插件或外部服务。

编导层的唯一交付物是已有的 `DirectorLockedManifest`。素材层只能读取这个锁定版本，不能从多个编导节点自行拼装。

```text
叙事与全局意图
        + 语音时序与字幕
        + 镜头拆解与节奏
        + 视觉规格与路线候选
        -> 编导数据收口门
        -> DirectorLockedManifest (DIRECTOR_LOCKED)
        -> 素材层按 requirement_id 生产
```

## 2. 四类编导子计划

| 子计划 | 主要职责 | 收口内容 | 不能做的事 |
| --- | --- | --- | --- |
| `narrative_intent` | 叙事目标、段落意图、全局视觉方向 | 大镜头文本、节奏、段落目标 | 不生成素材 URL |
| `timing_subtitles` | TTS、真实语音时长、字幕细分 | 大/小镜头时间线、字幕文本与时间线 | 不把估算时长当真实时长 |
| `shot_breakdown` | 小镜头规划与镜头节奏 | `shot_id`、顺序、`source_text`、`clip_role`、`story_beat` | 不改变上游数组顺序 |
| `visual_route` | 语义视觉规格与路线判断 | `VisualSpec`、路线候选、Host/普通画面分支条件 | 不生成供应商最终提示词 |

TTS 属于编导时序收口的一部分。当前节点 `159953 speech_synthesis` 已归入编导层；它的音频生产仍然依赖外部 TTS transport，但其结果一旦用于锁定时间线，就必须在编导门内版本化。

## 3. VisualSpec 与 PromptPackage 的边界

编导层只保存语义视觉规格，例如主体、场景、景别、视角、构图、动作意图和参考素材需求。素材层再把 `VisualSpec` 编译成模型/供应商专用的 `PromptPackage`。

编导锁定对象禁止出现：`prompt`、`video_prompt`、`image_prompt`、`model`、`provider`、`api_key`、`endpoint`、`request_payload` 和 `official_fallback` 等字段。被脱敏的真实运行只能保存 `observed_fields` 和来源证据，不能补造长文本或 URL。

## 4. 收口门检查

收口函数为 `validate_director_convergence()`，通过条件如下：

1. 四类子计划顺序固定为叙事、时序字幕、镜头拆解、视觉路线。
2. `project_id`、`run_id`、`plan_version` 在所有子计划和 `DirectorLockedManifest` 中完全一致。
3. 大镜头、小镜头、字幕、素材需求的数量、ID、嵌套关系和数组顺序保持不变。
4. 所有 `start/end` 使用整数微秒；大镜头连续覆盖总时间线，小镜头连续覆盖所属大镜头，字幕落在所属大镜头内。
5. `VisualSpec` 与小镜头一一对应；路线候选与原节点顺序一致，不能伪造已完成的素材选择。
6. 编导对象中不存在素材层提示词或外部请求载荷。
7. 真实数据缺失时只能标记 `OBSERVED_REDACTED`，不能伪造 `READY`、URL、task_id 或模型成功状态。

收口通过后，状态为 `DIRECTOR_LOCKED`。收口报告中的 `real_fixture_observed_with_redaction` 只表示真实脱敏样本结构通过，不表示真实模型或剪映全链路验收通过。

## 5. 当前真实成功案例基线

使用执行记录 `7668196429877870619`：9 个大镜头、17 个小镜头、61 条字幕，总时长 `111672000` 微秒。VisualSpec 和路线数据中仍有脱敏/仅形状观测字段，因此当前证据级别为 `real_fixture_observed_with_redaction`，素材层和剪辑层仍需各自通过真实 URL、任务状态、草稿结构和客户端打开验收。

## 6. 失败与失效

- 项目、运行或版本不一致：拒绝收口。
- 数组缺失、重复、乱序：拒绝收口。
- 时间线有空洞、重叠、越界或单位错误：拒绝收口。
- 提示词或外部请求字段泄漏到编导层：拒绝收口。
- TTS、模型或路线仅有创建回执而没有真实结果：保留 `OBSERVED_REDACTED` 或进入阻断，不得宣称生产完成。
- 原文、TTS、镜头顺序变化时，必须生成新的 `plan_version`，旧锁定版本不得覆盖。
