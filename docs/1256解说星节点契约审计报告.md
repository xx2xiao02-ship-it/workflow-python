## 已读取的插件行为

从 `capcut-mate` 的 `add_audios` Schema 和服务实现中确认：

1. `audio_infos` 必须是 JSON 字符串，解析后必须是数组。
2. 每项必须是对象，`audio_url` 必须以 `http://` 或 `https://` 开头。
3. 服务层要求 `audio_url`、`start`、`end`，缺失字段抛出输入错误。
4. 归一化字段顺序为 `audio_url`、`duration`、`start`、`end`、`volume`、`audio_effect`。
5. `volume` 默认 `1.0`，超出 `[0.0, 2.0]` 时回退到 `1.0`。
6. `start/end` 要求数值且 `end > start`，随后转成整数微秒并再次检查。
7. `duration` 非空且小于等于 0 时抛出输入错误。
8. 通过校验后才创建音频轨道、添加片段、保存草稿并返回结果。
