# 1256“镜头精细化导演”Seed 2.1 turbo 接入说明

## 官方依据

- [火山方舟文本生成](https://docs.volcengine.com/docs/82379/1399009?lang=zh)
- [火山方舟深度思考与 thinking 参数](https://docs.volcengine.com/docs/82379/1449737?lang=zh)

官方模型标识为 `doubao-seed-2-1-turbo-260628`，Chat API 地址为：

`https://ark.cn-beijing.volces.com/api/v3/chat/completions`

关闭思考使用：

```json
{"thinking":{"type":"disabled"}}
```

官方文档列明 `doubao-seed-2-1-turbo-260628` 支持 `enabled`、`disabled`、`auto` 三种思考模式；本项目按用户选择固定使用 `disabled`。

## 节点映射

本配置用于 `197742 镜头精细化导演`，不是 Seedance 视频生成节点。原始 8364 YAML 中该节点输入为 `duration`、`segments`、`items`，输出为 `shots`、`reasoning_content`；原模型为“豆包·2.0·pro”。

Python 适配器：`src/workflow_1256/shot_refinement_transport.py`

批处理和字段顺序仍由 `src/workflow_1256/shot_refinement.py` 管理，未改变 `LLM_list`、`Code_list` 或下游 `127095` 的契约。

## 本机配置

密钥不写入项目。真实执行前，在项目 PowerShell 窗口中设置：

```powershell
$env:SHOT_REFINEMENT_PRIMARY_API_KEY = "在本机安全填写主鉴权"
$env:SHOT_REFINEMENT_BACKUP_API_KEY = "在本机安全填写备用鉴权"
```

可选配置：

```powershell
$env:SHOT_REFINEMENT_API_URL = "https://ark.cn-beijing.volces.com/api/v3/chat/completions"
$env:SHOT_REFINEMENT_MODEL = "doubao-seed-2-1-turbo-260628"
$env:SHOT_REFINEMENT_TIMEOUT = "180"
$env:SHOT_REFINEMENT_MAX_ATTEMPTS = "3"
```

鉴权顺序为主鉴权优先；主鉴权在每轮尝试失败后切换备用鉴权。密钥只从本机环境变量读取，不写入代码、样本、日志或报告。

当前只完成 transport 的本地请求契约测试，未调用真实方舟接口，因此尚不能宣称真实模型等价验收通过。
