## 保留的原始行为

- 字符串字段最多递归 JSON 解析 5 层；非法 JSON 保留为原字符串，再由 `as_list/as_dict` 决定是否回退为空数组/对象。
- `clip_duration` 支持直接数组以及 `clip_duration`、`clip_durations`、`duration_list`、`durations` 四种对象字段。
- 时长通过 `float` 转换，非正数和无效值变为 `0`，非整数使用 `round(value, 1)`，因此 `4.25` 按 Python 舍入为 `4.2`。
- `motion_seed` 支持字符串和对象中的 `motion_seed`、`seed`、`text`、`content` 字段。
- 图片支持字符串和对象中的 `image_url`、`url`、`link`、`image`、`src` 字段。
- 每组镜头数优先取 `clip_duration` 数量，否则取 `LLM_list` 中 `shots` 数量，再否则取 `items` 数量。
- `ref_image_f` 是当前组全部首帧；`ref_image_e` 是下一张首帧组成的尾帧数组，因此 N 个镜头得到 N 张首帧和 N-1 张尾帧。
- 组数、镜头数、种子数、图片数不一致时不抛异常，而是继续生成可用数组并把中文诊断拼接到 `error`，该行为已保留。
- 多余的 `motion_seed` 和 `image_url_list` 在全部分组处理后追加“未被使用”错误。
