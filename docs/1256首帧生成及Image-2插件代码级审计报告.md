## 输入输出行为审计

### create_image_task

- 必填参数：`api_key`、`prompt`；缺失时返回原始中文错误对象。
- `n` 只有 `str(value).isdigit()` 时转整数，否则回退为 `1`。
- `size` 默认 `auto`，`resolution` 默认 `1k`，非列表 `image_urls` 回退为空数组。
- 成功创建只拿到 `task_id`，返回 `code=202`、`status=processing`，最多尝试 3 次。
- HTTP 400/401/403/404 立即返回；其余 HTTP 错误和网络异常按原始延迟策略重试。
- 成功源码返回中包含 `attempted`，但 YAML 输出配置没有该字段；Coze 页面将未返回的 `image_url` 显示为 null，并只显示配置声明的字段。新实现提供显式 `to_coze_node_output()` 投影，不把平台包装逻辑混入算法。

### get_task_result

- 输入先按属性对象或 `.get()` 对象读取，再去除 task_id/API key 两侧引号。
- 缺失 `task_id` 或 `api_key` 时返回原始错误对象。
- `completed` 时从 `data.result.images[0].url[0]` 取图片地址；结构缺失时原行为回退为空字符串。
- `failed` 时返回 `code=500` 和失败消息。
- 处理中每 30 秒轮询；超过 172 秒，在最后一次查询后抛出 `ActiveCrashError`。
- HTTP 错误直接返回状态码和截断响应；网络异常等待 2 秒继续，截止后抛出主动熔断异常。
- 页面真实成功记录显示平台输出有 `errorBody=null`、`isSuccess=true`、`message=null`；源码的 `msg` 不自动等价为声明字段 `message`。新实现提供显式 `to_coze_node_output()` 投影，并把该平台包装差异列为待真实异常场景验证项。
