# 编导层真实测试清单 v1

## 一、测试输入

- [ ] 完整文案：保留原文，不在测试台内改写。
- [ ] 大配音分段：一行一个分段，顺序与 TTS 输入一致。
- [ ] 大分段时间线：优先使用真实 TTS 的微秒 `start/end`；没有真实 TTS 时只能标记 synthetic。
- [ ] 画风参考图：至少 1 个可被外部图片模型访问的 URL。
- [ ] 主角设定：姓名、年龄感、职业、服装和人物目标。
- [ ] 模式：契约测试或真实模型测试。

## 二、编导输出验收

- [ ] `movie_outline` 完整：主角、目标、核心冲突、人物弧光、结尾悬念。
- [ ] `silent_story_text` 是连续默片故事，不出现对白、聊天记录或解释字幕。
- [ ] `scene_groups` 在 3～5 组之间；不能机械地每个大分段独占一个场景。
- [ ] 每个 `group_id` 恰好出现一次，顺序保持 `g01…gNN`。
- [ ] 每个大分段都有 `semantic_mapping`、`silent_action`、`metaphor` 和前后状态。
- [ ] 场景之间有状态变化和承接，不是逐句配图。

## 三、角色资产验收

- [ ] 角色锚定图只生成 1 次，资产标识为 `project.image.character_anchor`。
- [ ] 角色锚定图继承参考图的画风、色彩、材质和人物气质。
- [ ] 人物镜头的 `ref_image` 首位是角色锚定图。
- [ ] 物件、空间、建筑远景镜头不强行注入角色图。
- [ ] 角色图 URL 可被后续首帧服务访问。

## 四、后续首帧与视频验收

- [ ] 每个镜头只生成一张首帧图。
- [ ] 首帧镜头时间线与真实 TTS 时间线一致，单位为微秒。
- [ ] 人物镜头的脸、发型、服装主色和体态稳定。
- [ ] 每个镜头控制在 3～6 秒软目标内。
- [ ] 真实输出、synthetic 输出和失败原因分别记录，不能混用。
